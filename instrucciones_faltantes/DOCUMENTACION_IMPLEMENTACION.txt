## 📋 INSTRUCCIONES PARA PROBAR EL BACKEND

### 1. INICIAR SERVIDOR
```bash
php artisan serve
```

### 2. PROBAR LOGIN (POSTMAN)
```http
POST http://127.0.0.1:8000/api/login
Content-Type: application/json

{
  "email": "admin@gimnasio.com",
  "password": "password"
}
```

### 3. USAR EL TOKEN EN SUBSECUENTES PETICIONES
```
Authorization: Bearer <token_del_login>
```

### 4. PROBAR ENDPOINTS SEGÚN ROL
- Con token de admin: probar endpoints de /api/clients, /api/plans, etc.
- Con token de trainer: probar endpoints de /api/routines
- Con token de client: probar endpoints de /api/my-*

### 5. CREAR DATOS DE PRUEBA
```http
POST http://127.0.0.1:8000/api/clients
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "name": "Juan Pérez",
  "email": "juan@gmail.com",
  "password": "password123",
  "phone": "123456789"
}
```
